# Charles N. Kalungu — Personal Portfolio Website

A responsive, static personal portfolio designed for GitHub Pages.

## Files
- `index.html` — website content and sections
- `style.css` — layout, colours and responsive design
- `script.js` — mobile navigation and current year
- `assets/documents/` — place public PDF documents here
- `assets/images/` — place your profile photo and other images here

## Preview on your computer
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click `index.html` to preview in your browser.

## Publish with GitHub Pages
1. Sign in to GitHub.
2. Create a new **public** repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload the contents of this folder to the repository's top level. Ensure `index.html`, `style.css` and `script.js` are visible at the top level, not inside another nested folder.
4. Open repository **Settings** → **Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for the deployment to finish. Your site should be available at `https://YOUR-USERNAME.github.io`.

For an ordinary project repository instead, the address is usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Personalise before publishing
- Replace `YOUR-EMAIL@example.com` and the LinkedIn/GitHub links in `index.html`.
- Replace the CK initials with a professional photo if desired. Put the photo in `assets/images/` and update the profile block in `index.html`.
- Add your CV PDF as `assets/documents/Charles-Kalungu-CV.pdf`.
- Add verified dates, other attachment locations, appointments, supervisors, awards and qualifications.
- Remove any sections or details that are not accurate.

## Privacy checklist
GitHub Pages websites are public. Do not upload national ID/passport numbers, home address, personal phone number unless you intend it to be public, signatures, private student records, confidential institutional documents, or certificates showing sensitive identifiers. Consider publishing redacted copies of certificates.
