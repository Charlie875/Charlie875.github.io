INSTALL ON GITHUB PAGES
1. Extract this ZIP file.
2. Upload index.html, style.css and script.js to the root of your repository.
3. Upload the complete assets folder, preserving the folder structure.
4. Copy your CV PDF into assets/documents/ and name it exactly:
   Charles-Kalungu-CV.pdf
5. Commit the changes. Your website should publish at:
   https://charlie875.github.io

CV REQUEST FORM
The WhatsApp option opens a pre-filled chat; the visitor must press Send.
Email notifications are not active until you configure EmailJS. Replace the three
YOUR_EMAILJS... values in script.js with your EmailJS public key, service ID and
template ID. Set the EmailJS template to send to kalungucharles9@gmail.com.

PHOTO
The photo is already included at assets/images/Charles-kalungu.jpg.
Do not rename or move it unless you also update the image path in index.html.
